# JobSniffer — Robota.ua Remote Vacancies Explorer

<img width="1920" height="1020" alt="image" src="https://github.com/user-attachments/assets/da1c161f-37ae-4ea8-bc79-61081bc59718" />

JobSniffer — настільний застосунок для Windows на Python і PyQt6, який завантажує віддалені вакансії з Robota.ua, фільтрує їх за чорним списком і дозволяє швидко переглядати деталі.

## Можливості

- пошук вакансій через Robota.ua API;
- фільтр лише віддалених вакансій;
- автоматичний добір вакансій до вибраного ліміту;
- локальний пошук у завантаженому списку;
- чорний список слів і фраз;
- вкладка прихованих вакансій із причиною блокування;
- світла та темна теми;
- регульована ширина колонок таблиць;
- відкриття вакансії у браузері та копіювання посилання;
- збереження налаштувань між запусками.

## Запуск із Python

Потрібні **Python 3.10+** і Windows 10/11.

```bat
py -m pip install -r requirements.txt
py main.py
```

Або запустіть подвійним кліком:

```text
run.bat
```

Скрипт автоматично переходить у папку проєкту, тому його можна запускати незалежно від поточної робочої директорії.

## Створення готового exe

Щоб отримати продукт, який запускається без відкриття консолі та без ручного виклику `main.py`:

1. Відкрийте папку проєкту у Windows.
2. Запустіть `build_windows.bat`.
3. Після завершення відкрийте файл `dist/JobSniffer.exe`.

Скрипт автоматично встановлює PyInstaller, очищує попередню збірку, додає `JobSniffer.ico` як іконку exe та пакує застосунок у один файл.

Налаштування користувача зберігаються поруч із готовим exe у `settings.json`, тому вони не втрачаються після перезапуску.

## Іконка

`JobSniffer.ico` використовується як:

- іконка головного вікна;
- іконка застосунку в Windows;
- іконка готового `JobSniffer.exe`.

## Структура

- `main.py` — точка входу та запуск застосунку;
- `api.py` — робота з API Robota.ua;
- `models.py` — моделі вакансій;
- `storage.py` — налаштування та збереження стану;
- `filter_engine.py` — фільтрація вакансій;
- `workers.py` — фонові потоки завантаження;
- `ui/` — головне вікно, таблиці, чорний список, деталі та стилі;
- `JobSniffer.ico` — іконка застосунку;
- `run.bat` — запуск із Python;
- `build_windows.bat` — створення готового exe;
- `requirements.txt` — залежності проєкту.

## Гарячі клавіші

| Клавіша | Дія |
|---|---|
| `F5` або `Ctrl+R` | Оновити список вакансій |
| `Ctrl+F` | Фокус на локальному фільтрі |
| `Ctrl+K` | Фокус на пошуку Robota.ua |
| `Enter` на вакансії | Відкрити вакансію у браузері |
